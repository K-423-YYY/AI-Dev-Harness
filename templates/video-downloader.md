# 项目模板：万能视频下载总结器（方案 A2 标准案例）

> 使用方式：把本模板内容作为参考，让引擎生成计划书时指定"按 video-downloader 模板"。也可直接复制本文件为 `docs/plan.md` 的基础后让 AI 补全。

## 目标
一个支持任意视频链接下载并生成 Markdown 总结的"万能视频下载总结器"。

## 需求补全
- 目标用户：需要下载并总结视频内容的个人用户
- 核心场景：粘贴视频链接 → 解析下载 → 生成 Markdown 总结（含字幕、思维导图导出）
- 范围外：本期不做视频剪辑与转码
- 技术选型：下载核心 YT-DLP（Python）、后端 Python（FastAPI/Flask）、前端界面 + SEO/GEO 优化、支付 Stripe 国际支付
